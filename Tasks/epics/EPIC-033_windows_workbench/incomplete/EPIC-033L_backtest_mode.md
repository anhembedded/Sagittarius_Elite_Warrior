## 1. Context and problem
Backtest is a page whose parameter bar of pill dropdowns clips at 1366 px, scrolls a chart inside a page scroll, and owns 16 hand-styled dialogs.

## 2. Acceptance criteria
- [ ] Run setup is a dock (or one Run Settings… dialog) with market, symbol, strategy, timeframe, range, timezone, capital and execution; Run backtest is an action (F7, HLD §11.2.3) and Stop backtest is enabled only while a run runs. *(Corrected 2026-10-05: the task said F5, which keeps its standard meaning, Refresh, and HLD §11.2.3 gives F7; "Stop replaces Run" would hide a command, which `ui-presentation-rule.md` §2 forbids — the two actions stay, and each is disabled while it does not apply.)*
- [ ] The central widget and default docks are exactly those HLD §11.2.1 lists for this mode (the one list; this task does not copy it). Every remaining dialog is a stock `QDialog` with `QDialogButtonBox`.
- [ ] Every command of the mode is an action in its menu and, when frequent, its toolbar; every table and read-out is built from its spec; the mode passes the conformance suite with no baseline row.
- [ ] The SPECs above still pass their "Proven by" tests; any changed flow updates its SPEC in the same pull request.

## 3. Design
The mode's wireframe approved in EPIC-033O is the design; this task builds it on `WorkbenchShell` with stock controls. Presenters, coordinators and view models are reused where their behaviour fits the approved design; views are new. It replaces: the Backtest screen and its 16 dialogs.

### Stages (one pull request each)
1. **Re-host into the workbench.** A left-dock place (`Place.NAVIGATOR` → `DOCK_LEFT`); the view on a `WorkbenchSurface`: result chart central, Run setup left (`RunSetupPanel`, a form of stock controls replacing the pill toolbar), Metrics right (the banners and figures), Trades bottom. `PageShell`, the page scroll area and the splitter's 1000 px of minimum heights go; `IBacktestView`'s 19 members are unchanged.
2. **Stock controls**, in two pull requests. **2a:** the trades list becomes a table built from its column specs, with a filter, a search and the selected trade's journal; Drawdown and Monthly returns become bottom docks; the panel's Export button becomes Tools → Export trades…. **2b:** Monte Carlo becomes a bottom dock beside Trades; progress moves to the status bar.
3. **Dialogs and fields**, in two pull requests. **3a:** the simple pickers (strategy, timeframe, range, time zone) become drop-down fields of the Run setup; the range's "Custom…" opens the calendar dialog. **3b:** Capital, Limitations, Execution and Indicators become `QDialog`s with a `QDialogButtonBox`. **3c:** Metrics detail, the two comparisons and Strategy properties do the same. *(Moved from 2b, 2026-10-05: the pickers are the overlays this stage rebuilds, so they change once.)*
4. **Clean-up.** The mode's baseline rows and ratchet entries reach zero.

## Implementation notes (written when done)
**Stage 1 (2026-10-05).** `src/core/contracts/place.py` gains `NAVIGATOR` (the left dock: what the centre is picked or set up from), mapped to `RegionKind.DOCK_LEFT` in `workbench_surface.py` and filled after the workspace in `surface_building.py`; the vocabulary, HLD §4/§11.2.5 and SDD-02 list it. `BackTestView` hosts a `WorkbenchSurface` (`BACKTEST_SURFACE`, held equal to `shell/surfaces.py` by `test_backtest_mode_layout.py`) with the docks Run setup, Metrics and Trades. `run_setup_panel.py` is the old toolbar as a `QFormLayout`; values are escaped so an ampersand never becomes an access key. The trades panel keeps its `BUG-004` minimum height until stage 2 replaces its hand-built rows. Measured: `no_nested_scroll` leaves the conformance baseline; style-sheet calls 89 → 78; `backtest_top_panel.py` 734 → 497 lines. Review of PR #355: the Run setup's access keys took Alt+T, Alt+E and Alt+R from Tools, Edit and Trade; they now avoid every menu-bar key, which `test_backtest_mode_layout.py` derives from the shell's menus and every contributed command. The four figures abreast made Metrics 563 px wide and left the chart 558 px of 1366; two to a row and a two-line header leave it 771 px, held by a test. A perspective saved before this change has nothing to restore: the screen had no surface, so `ModeHost` saved none for it.

**Stage 2a (2026-10-05).** `trade_table_model.py` (`TradeTableModel`) holds each `TradeLogRow` as raw values under ten column specs — number, side, entry and exit time and price, quantity, size, net profit, return — with the profit and return coloured by sign as well as signed. The panel (`backtest_trade_logs_panel.py`, rewritten) is a "Show:" combo box, a "Find:" field with a clear button, the `SpecTable`, and a form of the selected trade's journal (`trade_details()`: entry and exit reason, duration, MAE, MFE, the strategy's metadata). Selecting a row is `PROP-001`'s chart link. Times are written in the mode's display time zone through `ZonedValueFormatter` (`support/ui_kit/value_formatter.py`), which asks the zone when it writes; the coordinator resets the model on a zone change. The view model holds raw rows and no page: the table scrolls, so pagination (`trade_log_pagination.py`, twenty rows a page) and the `BUG-004` floor went; the visibility test now asserts the table's first row is on screen. `trade_log_row_to_qml` and the hand-built row, filter-tab and column files are deleted. Drawdown and Monthly returns are bottom docks (`result_panels.py`) tabbed with Trades; `activeBottomTab` went with the tab bar. Export is Tools → Export trades…, enabled while trades are listed. Measured: style-sheet calls 78 → 52, `apply_role` 32 → 31, `backtest_trade_logs_panel.py` 443 → 192 lines and off the god-file list.

**Stage 2b (2026-10-05).** The run's and the sync's progress is the status bar's (`run_progress_status.py`, `IStatusSource`), shown in every mode while a run, a sync or its stop is under way; Stop is Tools → Stop backtest, so the Metrics panel's progress banner and its Cancel button are gone. Monte Carlo is a bottom dock (`monte_carlo_panel.py`, the former `MonteCarloDialog` without its overlay); Tools → Monte Carlo shows and raises it. Because the panel stays open while runs come and go, `RunResultViewModel` gained `comparisonSnapshotChanged`: a dialog re-read the run when opened, a panel must be told. Review of PR #360: the Monte Carlo and Trades panels' labels took Alt keys the Run setup and the File menu already held; every access key of the mode is now unique and off the menu bar, held by one test over the whole view. The panels are built and docked in one place (`backtest_panels.py`). Measured: `backtest_top_panel.py` 497 → 418 lines; style-sheet calls 52 → 51.

**Stage 3a (2026-10-05).** Strategy, timeframe, range and time zone are `QComboBox` fields of the Run setup (`run_setup_choices.py`: `Choice`, `fill_combo` and one offer per field). A field fills without announcing and acts on `activated`, so only a person's pick reaches the view model and choosing the current item again still acts. The range offers the view model's presets and "Custom…" last; choosing it asks for the dates in the calendar dialog (`TimeRangePickerDialogWidget`) and the field shows the range still in effect until they are applied, then "Custom…" with the dates as its tooltip. A field does not size the dock to its longest item (`AdjustToMinimumContentsLengthWithIcon`): a time zone's name took the chart below half the window. `StrategyPickerDialog`, `TimezonePickerDialog`, the Backtest timeframe picker and their three `open…Requested` signals are deleted; the timeframe list loses its pinned favourites, a picker feature with nothing in a drop-down list to hold it. `test_run_setup_choices.py` restates the pickers' promises over the fields. Measured: `backtest_view_model.py` 805 → 790 lines; two mypy excludes go with their files.

**Stage 3b (2026-10-05).** Capital, Limitations, Execution and Indicators are stock `QDialog`s titled after the command that opens them, their buttons a `QDialogButtonBox`. Capital is a form of the amount and the currency with OK and Cancel; the verdict still has one writer, which disables OK. Limitations is its list and Close. Execution applies as it is clicked, so its button is Close: the two exclusive triggers, bar close and every historical tick, are radio buttons, so bar close is a choice rather than a locked box left only by checking its rival; "On order fill" is a check box; the real-time row stays locked and checked. Indicators is one check box per registered script, rebuilt on every model reset, and says so when none is registered. The currency combo's 90 px floor went with the overlay (`fixed_size` 1 → 0 for `capital_dialog.py`).

**Stage 3c (2026-10-05).** Metrics Detail, In-Sample vs Out-of-Sample, Compare Reports and Strategy Parameters are stock `QDialog`s. The three read-outs keep their trees and close with a `QDialogButtonBox`; Metrics Detail's Copy all is an action-role button in it. Strategy Parameters has two tabs, Inputs (each strategy group a group box) and Properties (`broker_properties_tab.py`: capital, order size, commission and slippage, leverage, take profit, each a group box holding a form); Save, Cancel and Restore Defaults are the platform's buttons. The two "Coming soon" tabs, Style and Visibility, are gone. `_layout.py`, the styled section-header and field helpers, is deleted. Every Backtest dialog now opens with `QDialog.open()`. Measured: style-sheet calls 51 → 41 in 14 → 12 files, palette files 19 → 17, `strategy_properties_dialog.py` 441 → 303 lines and off the god-file list.
