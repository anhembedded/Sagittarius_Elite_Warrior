### 🗺️ Mô hình Luồng Trạng thái Mới (FSM State Flow):

```mermaid
stateDiagram-v2
    [*] --> IDLE: Mở màn hình

    IDLE --> RUNNING: Bấm "Chạy Backtest" (Params Valid)
    IDLE --> SYNCING: Bấm "Đồng bộ ngay" (Khi thiếu data)
    IDLE --> CONFIG_DIRTY: Thay đổi TF / Strategy / Range / Vốn

    CONFIG_DIRTY --> RUNNING: Bấm "Chạy Backtest"
    CONFIG_DIRTY --> SYNCING: Bấm "Đồng bộ ngay"

    RUNNING --> COMPLETED: Backtest thành công (Có Trades)
    RUNNING --> EMPTY_DATA: Thiếu dữ liệu nến (Đề nghị Sync)
    RUNNING --> CANCELLING: Bấm "Hủy" (Cancel Token)
    RUNNING --> ERROR: Ngoại lệ / Lỗi thuật toán

    CANCELLING --> IDLE: Hủy hoàn tất (Trả lại quyền điều khiển)
    
    COMPLETED --> CONFIG_DIRTY: Thay đổi TF (1m→5m) / Strategy / Vốn / Range
    COMPLETED --> RUNNING: Bấm "Chạy lại"

    SYNCING --> RUNNING: Tự động chạy tiếp sau khi Sync xong
    SYNCING --> ERROR: Sync thất bại

    EMPTY_DATA --> SYNCING: Bấm "Đồng bộ ngay"
    EMPTY_DATA --> CONFIG_DIRTY: Đổi sang TF / Range khác

    ERROR --> IDLE: Reset / Thao tác lại
```
