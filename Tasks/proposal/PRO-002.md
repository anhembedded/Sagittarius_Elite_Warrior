## 2. Giải Pháp Kiến Trúc & Design Patterns

### 2.1. Phân Rã `BacktestPresenter` (2,523 dòng) $\rightarrow$ Sub-Coordinator Pattern
Tách thành các coordinator độc lập trong `src/presentation/ui/screens/backtest/coordinators/`:
* `execution_coordinator.py`: Điều phối chạy Static & Realtime backtest, cancellation, progress.
* `data_sync_coordinator.py`: Quét range coverage, auto-sync dữ liệu thiếu.
* `chart_render_coordinator.py`: Đồng bộ dữ liệu sang Chart Host (Python / Native QML).
* `indicator_coordinator.py`: Tính toán Script / Indicators, series overlay.
* `trade_log_coordinator.py`: Định dạng trade log, phân trang và xuất CSV.
* `strategy_config_coordinator.py`: Binding tham số chiến lược, SL/TP, Đòn bẩy.

### 2.2. Phân Rã `BacktestViewModel` (1,113 dòng) $\rightarrow$ Composite ViewModel Pattern
* `BacktestConfigViewModel`: Quản lý thông số cấu hình đầu vào.
* `BacktestMetricsViewModel`: Quản lý các chỉ số thống kê (Sharpe, Sortino, Drawdown, Win Rate).
* `BacktestChartViewModel`: Quản lý viewport range, backend selection, overlay toggles.

### 2.3. Modular Hóa Các File QML Lớn $\rightarrow$ Component Modularization
* `DatabaseScreen.qml` (893 dòng) $\rightarrow$ Tách `DatabaseStorageTable.qml`, `DatabaseStatsCard.qml`, `DatabaseSyncControls.qml`.
* `BackTestTopPanel.qml` (724 dòng) $\rightarrow$ Tách `BacktestStrategySelector.qml`, `BacktestDateRangeControls.qml`, `BacktestExecutionControls.qml`.
* `StrategyPropertiesModal.qml` (696 dòng) $\rightarrow$ Tách `StrategyParamsTab.qml`, `StrategyRiskTab.qml`, `StrategyLeverageTab.qml`.

### 2.4. Phân Rã `PaperExchange` (603 dòng) $\rightarrow$ Domain Policy Pattern
* `MarginRiskPolicy`: Tính toán ký quỹ, Maintenance Margin, Margin Call, Liquidation.
* `OrderMatchingPolicy`: So khớp lệnh Limit / Market / Stop theo nến hoặc tick.
* `FeeCalculatorPolicy`: Tính phí giao dịch Maker/Taker, Funding fee.
