# BUG-006 — Backtest trade markers overlap until the chart is unreadable

**Reported:** 2026-08-17  
**Status:** Fixed by `BOT-098A1`  
**Area:** Backtest chart / trade flags

## Observed business defect

A Backtest result with 930 LONG trades produces roughly 1,860 entry/exit
labels. At a multi-day zoom level the chart paints every visible
`MUA (LONG)` and `ĐÓNG LONG` label. Labels cover candles, indicators, axes and
each other, so the user cannot read price action or identify useful trades.

The marker wording from `BOT-096` is truthful; the density policy is not.
TradingView-style behavior should reveal exact events when zoomed in and use a
truthful lower-detail representation when the available pixels cannot fit all
labels.

## Root cause

`MarkerLayer` retains full history and culls markers outside the X viewport,
but materializes one `pg.TextItem` for every marker inside the viewport. Its
cost and clutter therefore remain linear in the number of visible markers.

The old regression test asserted only that active items followed the visible
timestamp slice. It tested the implementation contract, not the business
contract that the chart remains readable.

## Required regression layers

1. Unit: deterministic marker LOD selection obeys a pixel budget, preserves
   marker semantics and preserves represented event count.
2. Component: a real `ChartCard` with a 930-trade-equivalent fixture retains
   all source markers but materializes a bounded display set; zooming in
   restores exact labels.
3. Integration: Backtest marker mapping remains truthful (`LONG_ENTRY` and
   `LONG_EXIT`) while flowing into the chart; no `SELL`/`SHORT` regression.
4. Desktop E2E/visual probe: real Backtest view, real Qt pan/zoom input and a
   large marker fixture verify bounded density, zoom restoration, non-empty
   rendering and clean Qt runtime messages.

Sanity remains construction-only. It must verify the real screen/plugin boots
cleanly, but it must not be misrepresented as coverage of this user journey.

## Acceptance criteria

- Full source marker history and exact entry/exit timestamps remain intact.
- Zoomed-out labels are bounded by chart pixel width and aggregate only equal
  semantic marker families; an aggregate badge exposes its represented count.
- The sum of represented counts equals the selected source slice.
- Zooming in below the density threshold restores every exact marker label.
- Pan away/back remains deterministic and does not leak scene items.
- The retained Desktop E2E probe uses real Qt input and checks render warnings.
- `scripts/ci-local.ps1 -Full` passes.
