# 📋 Sagittarius Elite Warrior Tasks

Chào mừng bạn đến với hệ thống quản lý Task của dự án **Sagittarius-Elite-Warrior**.

Hệ thống này được render tự động từ thư mục `Tasks/` của bạn. Bạn có thể sử dụng thanh menu bên trái để duyệt qua các trạng thái:
- 🚀 **Backlog**: Các task chờ thực hiện
- ⏳ **In Progress**: Các task đang làm
- ✅ **Completed**: Các task đã xong

> Dùng thanh tìm kiếm 🔍 ở góc trên bên phải để tìm nhanh các task theo nội dung hoặc ID.
